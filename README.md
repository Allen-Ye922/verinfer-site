# verinfer.com

Marketing site for Verinfer, served by Netlify at https://www.verinfer.com.

The site is a single self-contained page: `index.html` holds all markup, CSS and JavaScript, with no build step. `netlify.toml` publishes the repository root and sets basic security headers.

To preview locally, open `index.html` in a browser or run `python3 -m http.server` in this directory.
